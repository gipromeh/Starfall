# STARFALL — Asset Library

Единая библиотека игровых ресурсов. Игровые ассеты размещаются только здесь.

| Каталог | Назначение |
|---|---|
| ships/ | Корабли, истребители, транспорт, GLB |
| droids/ | Дроиды и автономные боевые платформы |
| planets/ | Планеты, спутники, звёзды, поверхности и текстуры |
| asteroids/ | Астероиды и малые тела |
| stations/ | Орбитальные станции и космические сооружения |
| convoys/ | Составы транспортных караванов и формации |
| nebulae/ | Туманности и объёмные космические объекты |
| weapons/ | Вооружение, турели и боевые ресурсы |
| artifacts/ | Артефакты и сюжетные объекты |

## Правила

1. Для каждого объекта — постоянный snake_case ID.
2. Модель, конфигурация, описание и лицензия хранятся рядом.
3. GLB проверяется на геометрию, масштаб, оси, текстуры и GPU-бюджет до runtime-интеграции.
4. Внешние ассеты не считаются игровыми объектами до прохождения проверки и подключения в runtime-каталог.
5. При изменении структуры обновлять этот README и SPACE_ASSET_CREDITS.md.

## Новая подборка

Импортированы 17 GLB-моделей NASA: астероид, две станции, космические аппараты и транспортный компонент. Структурная проверка всех 17 файлов: SPACE_ASSET_VALIDATION.md. Источники и условия: SPACE_ASSET_CREDITS.md. В runtime подключены Argo, Space Shuttle B и модуль Base Station; остальные модели остаются staged.
