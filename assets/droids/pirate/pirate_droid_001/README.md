# Pirate Droid 001

Каталог для GLB-модели пиратского космического корабля STARFALL.

## Файлы

- `model.glb` — основная 3D-модель; загрузить сюда.
- `config.json` — метаданные модели (будут добавлены после получения GLB).
- `textures/` — внешние текстуры, если они не упакованы в GLB.
- `animations/` — внешние анимации, если они не упакованы в GLB.
- `preview.png` — превью модели.

Не переименовывать `model.glb` без обновления конфигурации и ссылок на ассет.
