# STARFALL Weapon Assets

Ресурсы вооружения и боевых систем: лазерные установки, турели, ракетные установки, снаряды, боеприпасы, модели и визуальные эффекты.

## Рекомендуемая структура

```
weapons/
  <faction_or_class>/
    <weapon_id>/
      model.glb
      config.json
      README.md
      textures/
      animations/
      preview.png
```

Игровая логика, баланс и обработчики остаются в основном игровом коде/паспорте. Здесь хранятся самостоятельные ресурсы вооружения и их метаданные. Не дублируйте общие эффекты и материалы между вариантами оружия.
