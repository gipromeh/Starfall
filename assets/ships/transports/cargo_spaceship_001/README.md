# Cargo Spaceship

Гражданский грузовой корабль STARFALL.

- Игровая модель: `model.glb`.
- Игровая роль: нейтральный грузовой транспорт.
- Используется в обычном трафике и в качестве грузового корабля караванов.
- Модель нормализуется загрузчиком до 28 игровых единиц по наибольшему габариту.
- Двигательные сокеты создаются по габаритам GLB, если в модели нет именованных маркеров.
- При ошибке загрузки игра сохраняет штатную процедурную модель грузового корабля.
