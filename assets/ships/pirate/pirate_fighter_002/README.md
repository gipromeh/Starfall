# Pirate Fighter 002 — «Ржавый череп»

Пиратский истребитель, собранный скриптом `build_blender.py` (Blender 5.x, вкладка Scripting → Run Script). Скрипт сам строит геометрию, рисует текстуры (цвет, ORM, нормали) и по желанию экспортирует GLB (`EXPORT_PATH`).

- `model.glb` — 854 треугольника, 3 меша (hull / glow / cockpit), 3 материала, 3,06 МБ. Нос −Z (в Blender +Y), центр в нуле, 10,8 × 3,6 × 13,1 м.
- Метки в Blender (экспортируются пустышками): `ENG_0/1` — двигатели, `GUN_0…3` — стволы.
- Подключён в игру (v44): заменяет процедурного «Головореза» (`pirate`, тип 0), масштаб 0,75 (≈ габариты прежней модели). Если GLB не загрузился (нет сети, `file://`), игра использует процедурную модель.
- Просмотр: `assets/ships/viewer.html?ship=pirate_fighter_002`.
- Пересборка с другим износом: поменять `SEED` в `build_blender.py`, снова экспортировать GLB.
- Известно: текстура наложена плоскими проекциями (верх, низ, борт, нос), на круглых участках возможны растяжения.
