# Pirate Fighter 002 — «Ржавый череп»

Пиратский истребитель «Ржавый череп», собранный скриптом `build_blender.py` (Blender 5.x, вкладка Scripting → Run Script). Скрипт сам строит геометрию, рисует текстуры (цвет, ORM, нормали) и по желанию экспортирует GLB (`EXPORT_PATH`).

- `model.glb` — 854 треугольника, 3 меша (hull / glow / cockpit), 3 материала, 3,06 МБ. Игровая ось носа −Z, двигатели +Z; центр в нуле, 10,8 × 3,6 × 13,1 м.
- Blender-сборщик сохраняет исходную геометрию (нос +Y в Blender, +Z в GLTF). Игровой загрузчик и viewer проверяют фактический поворот и добавляют внешний runtime pivot Y=180°, если GLB не развёрнут.
- Blender-сборщик создаёт сокеты `ENG_0/1` (двигатели) и `GUN_0…3` (стволы). Старые GLB без этих узлов используют резервные игровые сокеты по координатам модели.
- Подключён в игру (v46): заменяет процедурного «Головореза» (`pirate`, тип 0) и выступает первым кораблём первой волны. Масштаб 0,75. Загружается с GitHub Pages; при ошибке загрузки используется процедурная модель.
- Просмотр: `assets/ships/viewer.html?ship=pirate_fighter_002`.
- Пересборка с другим износом: поменять `SEED` в `build_blender.py`, снова экспортировать GLB.
- Известно: текстура наложена плоскими проекциями (верх, низ, борт, нос), на круглых участках возможны растяжения.


## Игровые сокеты (GLB nodes)
- GUN_0…GUN_3 — четыре дульных маркера. Каждый выстрел создаётся в мировой позиции соответствующего маркера и рассчитывает собственную траекторию на точку упреждения.
- ENG_0, ENG_1 — два маркера двигателей. От них создаются пламя, выхлоп и дымовые следы.
- Игровой загрузчик добавляет внешний runtime pivot Y=180°, если GLB фактически не содержит такого поворота. Наличие узла с именем STARFALL_FORWARD_AXIS_FIX само по себе не доказывает правильную ориентацию.
