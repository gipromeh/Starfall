# Planet assets

Каталог внешних 3D-моделей планет для STARFALL — Void Hunter.

## Структура

Каждая планета хранится в отдельной папке с постоянным машинным идентификатором:

```
assets/planets/
├── README.md
├── catalog.json
├── eden/
│   ├── model.glb
│   └── preview.png          # необязательно
├── mars/
│   └── model.glb
└── saturn/
    └── model.glb
```

## Правила ресурсов

- Основной файл модели называется строго `model.glb`.
- Имя папки — стабильный ASCII ID в нижнем регистре: `earth`, `mars`, `saturn`, `eden`.
- Геометрия, UV, PBR-материалы и текстуры предпочтительно упаковываются внутрь GLB.
- Если текстуры вынесены отдельно, хранить их рядом с GLB в этой же папке и использовать относительные URI.
- ID должен совпадать с одним из штатных тел: `saturn`, `earth`, `mars`, `venus`, `eden`, `nyrea`.
- Загрузчик автоматически центрирует GLB и вписывает его максимальный габарит в диаметр существующей планеты. `scale` — дополнительный множитель (по умолчанию 1), `rotation` — XYZ в радианах.
- Модель наследует штатную орбиту и вращение соответствующей планеты. Радиус и параметры орбиты задаются игровым кодом, а не каталогом.
- Не класть сюда игровые корабли, станции, астероиды или исходники Blender — для них предназначены отдельные каталоги.
- Не перезаписывать существующую модель без проверки её использования и резервной копии.

## catalog.json

Манифест содержит массив `planets`. Для каждой записи предусмотрены поля:

- `id` — ID папки и соответствующей штатной планеты (`saturn`, `earth`, `mars`, `venus`, `eden`, `nyrea`);
- `name` — отображаемое имя;
- `model` — путь к GLB относительно корня репозитория;
- `scale` — коэффициент масштаба при импорте (по умолчанию 1);
- `rotation` — начальный поворот в радианах по XYZ (по умолчанию [0, 0, 0]);
- `notes` — заметки по модели.

Пример записи:

```json
{
  "schemaVersion": 1,
  "planets": [
    {
      "id": "mars",
      "name": "Марс",
      "model": "assets/planets/mars/model.glb",
      "scale": 1,
      "rotation": [0, 0, 0]
    }
  ]
}
```

Загрузчик читает каталог по HTTP(S). Если запись отсутствует или GLB не загрузился, штатная процедурная планета остаётся видимой. `file://` не поддерживается для каталога из-за ограничений браузерного `fetch`.

Добавление файла в каталог само по себе не подключает его к игре. Интеграция в сцену, освещение, вращение, орбита, LOD и мобильный профиль выполняются отдельным изменением загрузчика после проверки конкретной модели.
