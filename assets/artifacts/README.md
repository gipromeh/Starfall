# STARFALL Artifacts

Каталог уникальных игровых объектов: древние артефакты, реликвии, сюжетные предметы, коллекционные объекты и интерактивные находки.

## Рекомендуемая структура

```
artifacts/
  <origin_or_faction>/
    <artifact_id>/
      model.glb
      config.json
      README.md
      textures/
      animations/
      preview.png
```

В `config.json` фиксируйте постоянный ID, назначение, редкость, происхождение, способ получения и ссылки на связанные игровые события. Не размещайте здесь обычные корабли, дроидов или вооружение — для них существуют отдельные категории.
