# STARFALL — читать первым

Перед любой правкой прочитай `STARFALL_MASTER_INSTRUCTION.yaml` (секции `golden_rule` и `process`) и `STARFALL_PASSPORT.md`.

## ★ Золотое правило
**Не переписываем код. Только точечные изменения и добавления. Всё, что работает, не трогаем.**
Не тратим токены на пересборку работающего кода: Grep → Read нужного куска → Edit (old_string → new_string). Не Write всего `STARFALL_CURRENT.html`, не читать его целиком без причины.

## Процесс
- Источник правды — этот репозиторий, ветка `main`. Всё в проекте Claude — архив.
- Конец работы: обновить паспорт и `CHANGELOG.md`, один коммит `vNN: что сделано`, push в `main`.
- Перед коммитом: `node --check` основного скрипта (команды в паспорте §12).
