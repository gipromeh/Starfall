# STARFALL — PROJECT_DECISIONS

**Реестр:** 1.4  
**Рабочая база:** корневой `STARFALL_CURRENT.html`, Three.js r128, исходная версия v85.  
**Интеграционная версия:** v86.  
**Статус:** ниже приведены решения, явно согласованные пользователем. Неподтверждённые параметры остаются реализационными настройками.

## DEC-001. Тактический AI отделён от игровой физики
AI принимает тактические решения и формирует управляющие команды. Он не подменяет существующий контроллер движения.

## DEC-002. Физика полёта игрока сохраняется
Без отдельного согласования не менять управление, поворот, ускорение, торможение, сглаживание скорости, velocity, quaternion и интегрирование координат игрока. Локальные коэффициенты вражеского type 0 регулируются отдельным DEC-008 и не распространяются на игрока или другие классы.

## DEC-003. Ответственность AI
AI оценивает угрозы, выбирает поведение, направление, тягу и намерения применения оружия. Создание снарядов, попадания, урон и столкновения исполняют существующие игровые подсистемы.

## DEC-004. Основные тактические решения
AI поддерживает атаку, преследование и отход/бегство с учётом класса корабля и боевой ситуации.

## DEC-005. Гистерезис тактических состояний
Вход и выход из уклонения используют раздельные условия и временную фиксацию, чтобы избежать дребезга состояний. Выход из BREAK учитывает классический exit envelope.

## DEC-006. Индивидуальность классов
Поведение и манёвренность AI учитывают архетип корабля. Общие механизмы движения не меняются без прямого согласования.

## DEC-007. Единый реестр решений
Этот файл — единый источник утверждённых решений. Идентификаторы DEC уникальны, не переиспользовываются и не перенумеровываются. Предположения и временные настройки не объявляются решениями. При конфликте реализация подчиняется реестру, пока пользователь явно не утвердит изменение.

## DEC-008. Баланс скорости и манёвренности «Головореза» (type 0)
**Статус:** УТВЕРЖДЕНО.

Пользователь разрешил повысить скорость и скорость поворота только для type 0. В исходной реализации Pirate AI v1.2.2 утверждены значения: скорость 1.00 → 1.12; поворот 0.80 → 1.00; тактическая тяга 1.02 → 1.10; орбитальный коэффициент 0.42 → 0.30; манёвренность профиля 0.78 → 0.90.

**Перенос в v85/v86:** для E/E2 установлены speed multiplier 1.12, turn coefficient 1.00, steering acceleration 48 и начальная скорость 20. Профиль AI type 0 использует throttle 1.10, maneuverability 0.90 и orbit 0.30. Общий алгоритм интегрирования движения сохранён. Type 1–3 и игрок не менялись.

## DEC-009. Неоновая пиратская ливрея «Головореза»
**Статус:** УТВЕРЖДЕНО.

Только для type 0 добавлены процедурные неоновые надписи:
- верхняя панель: «ЕБАТЬ ВАШУ МАТЬ»;
- левый борт: «ИДИ НАХУЙ»;
- правый борт: «ХУЙ ВАМ».

Палитра: циан, пурпурный и кислотно-зелёный. Текстуры CanvasTexture и геометрические накладки используют существующий рендеринг/Bloom. Остальные классы не меняются.

## DEC-010. Тактический радар
**Статус:** УТВЕРЖДЕНО.

Радар имеет переключаемые диапазоны 500 м / 1 км / 2 км, подписанные кольца дальности, разные символы классов пиратов и типов контактов, индикацию высоты, векторы движения, выделение текущей цели и стрелки вражеских контактов за пределами диапазона. Сбор контактов отделён от их отрисовки.

## Инварианты v86
- Основной рендерер остаётся Three.js r128; Babylon.js не становится основным рендерером.
- Физика полёта игрока, управление, оружие, столкновения, урон и сохранения не переписываются.
- Существующая интеграция движения E/E2 сохраняется: поворот heading, сглаживание скорости, расчёт velocity и интегрирование position. AI только задаёт желаемое направление, тягу и разрешение на огонь.
- Отдельная эскадрилья `pirateFleet` и её сценарий группового налёта оставлены без изменений.
- Баланс type 1–3 не меняется.
