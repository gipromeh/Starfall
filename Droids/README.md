# Droids — отдельная лаборатория 3D-моделей

Эта папка изолирована от основного игрового кода STARFALL. Файлы здесь — самостоятельные HTML-прототипы процедурных моделей на Three.js.

## Содержимое

- [TIE Fighter — интерактивный 3D-просмотрщик](./TIE-Fighter/index.html)

## Правила

- Не подключать файлы этой папки к `STARFALL_CURRENT.html` без отдельного согласования.
- Каждая модель хранится в собственной подпапке.
- Прототипы запускаются независимо от основного игрового цикла STARFALL.
- Внешняя зависимость текущего TIE Fighter viewer — Three.js 0.160.0 с CDN.

> Примечание: TIE Fighter — истребитель, а не дроид. Папка Droids используется как отдельный каталог экспериментальных 3D-объектов по запросу пользователя.
