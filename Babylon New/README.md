# STARFALL — Babylon New

Отдельная миграционная ветка Three.js → Babylon.js. Production-игра и существующий каталог `Babylon/` не изменяются.

## First playable — Vertical Slice 01

В прототипе уже реализованы:
- камера преследования и видимый процедурный истребитель;
- инерционный полёт по исходным формулам STARFALL: W/S — газ, A/D — боковой манёвр, R/C — вертикаль, Shift — форсаж, X — торможение, Q/Z — крен, мышь — управление направлением;
- Yuka Vehicle + Seek steering для пиратского перехватчика, состояния APPROACH/BREAK;
- Rapier rigid bodies, collision events и ray-cast для лазерных попаданий;
- лазеры с перегревом, ракета с наведением при захвате цели;
- щит, корпус, топливо, перегрев и HUD;
- адаптивные сенсорные кнопки для мобильного экрана;
- Babylon.js рендеринг, звёздное поле, эмиссивные материалы и GlowLayer; GSAP для обратной связи интерфейса.

Это первый боевой срез, а не полная миграция игры. Экономика, станции, миссии, планетарная система, торговля, сохранения, добыча, гиперпрыжок, диалоги, аудио и полный HUD ещё не перенесены.
