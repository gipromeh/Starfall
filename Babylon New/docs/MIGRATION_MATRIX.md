# STARFALL — Three.js → Babylon.js

Исходный HTML — эталон поведения. Production-файл и существующий каталог Babylon/ не изменяются.

Основная игра использует Three.js r128. В исходнике также есть отдельный lazy-loaded Babylon.js 7.0 модуль бара. Используются EffectComposer/RenderPass/ShaderPass/UnrealBloomPass, tsParticles и Google Fonts.

Текущая основа — Vite, Babylon runtime boot, fixed-step loop, EventBus, InputAdapter и изолированное пространство сохранений. Это scaffold, не готовый порт.

Следующие этапы: извлечь схему состояния и сохранений; перенести корабли и FlightModel; бой и AI; окружение/NPC; экономику и UI; аудио/VFX/mobile UX; затем аддон сигналов.
