# STARFALL — Three.js → Babylon.js migration matrix

Исходный файл `reference/STARFALL — Void Hunter.html` — эталон поведения. Production-файл и существующий каталог `Babylon/` не изменяются.

## First playable — Vertical Slice 01

| Подсистема | Статус |
|---|---|
| Babylon.js scene / camera / render | Реализован базовый runtime |
| Истребитель игрока | Процедурная модель; геометрия исходника пока не портирована буквально |
| Инерция / ускорение / торможение | Перенесены формулы базового профиля исходника в FlightModel |
| Управление мышью и клавиатурой | Основные исходные клавиши перенесены |
| Форсаж и топливо | Базовая механика перенесена |
| Пиратский AI | Yuka Vehicle + Seek; упрощённые состояния APPROACH/BREAK |
| Физические тела | Rapier dynamic rigid bodies без гравитации |
| Столкновения | Rapier collision events, базовый урон при контакте |
| Лазеры | ProjectileSystem + Rapier ray queries |
| Ракеты | ProjectileSystem, прямой полёт и наведение при захвате |
| Щит / корпус / перегрев | DamageSystem, базовый профиль |
| HUD | Корпус, щит, перегрев, топливо, скорость, цель |
| Звёздное окружение | Базовое поле звёзд и дальние цветовые объёмы |
| Эффекты | GlowLayer и GSAP UI feedback |
| Мобильный ввод | Экранные кнопки и touch aim; реальная проверка на iPhone не выполнена |

## Ещё не перенесено

Экономика, торговля, станции, миссии, планеты и орбиты, добыча, гиперпрыжок, диалоги, персонажи, полный набор кораблей и пиратских ролей, грузовой трафик, сохранения, музыка/SFX, полный радар и исходная система интерфейсов.

## Следующие этапы

1. Сверить траектории FlightModel с исходной игрой на одинаковом вводе.
2. Перенести исходные модели кораблей, эффекты двигателей и оружия.
3. Довести пиратские тактические роли, уклонение и обход препятствий.
4. Перенести систему щитов/урона/перегрева и все типы оружия.
5. Перенести мир, станции, орбитальные объекты, экономику и прогресс.
6. Перенести интерфейс, аудио и мобильный UX.
7. Сравнить gameplay и производительность на Chromium desktop и iPhone Safari.
