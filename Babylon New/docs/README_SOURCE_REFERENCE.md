# Исходный эталон

Полная копия загруженного файла STARFALL — Void Hunter.html включена в локальный архив Babylon-New-migration-start.zip в каталоге reference/.

В GitHub-коммит этот HTML не включён: GitHub connector не предоставляет прямую передачу локального файла из рабочего каталога чата в Git blob API. Для локальной сборки скопируйте исходный HTML в Babylon New/reference/STARFALL — Void Hunter.html.

Не используйте STARFALL_CURRENT.html вместо этого эталона без сверки содержимого.
