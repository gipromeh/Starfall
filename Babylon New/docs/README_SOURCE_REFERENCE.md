# Исходный эталон

Полная копия загруженного исходного файла находится в репозитории:

`Babylon New/reference/STARFALL — Void Hunter.html`

Этот файл является reference-источником для миграции и не заменяет production-файл `STARFALL_CURRENT.html`. При портировании сравнивайте игровые параметры, управление, состояния и сценарии с этим исходником.

Production-версия `STARFALL_CURRENT.html` остаётся отдельным эталоном опубликованной игры. Не копируйте её поверх reference-файла и не меняйте её в рамках работ над `Babylon New/`.
