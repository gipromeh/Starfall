# STARFALL — Void Hunter

Браузерная 3D-игра в духе Galaxy on Fire 2 (Three.js, один HTML-файл, ПК + iPhone).

## Файлы

| Файл | Что это |
|---|---|
| `STARFALL_CURRENT.html` | **Единственная актуальная версия игры.** Брать за основу только её |
| `STARFALL_PASSPORT.md` | Паспорт: архитектура, переменные, таблицы баланса, правила правок |
| `CHANGELOG.md` | История версий |
| `STARFALL_MASTER_INSTRUCTION.yaml` | Мастер-инструкция по этапам (stages) и чек-лист приёмки |

## Библиотека игровых ресурсов

Все игровые ассеты хранятся в `assets/` и распределяются по категориям: `ships/`, `droids/`, `planets/`, `weapons/`, `artifacts/`. Описание структуры и правила размещения: [`assets/README.md`](assets/README.md). Каталог дроидов: [`assets/droids/`](assets/droids/); просмотрщик моделей кораблей: [`assets/ships/viewer.html`](assets/ships/viewer.html). Корневой каталог `Droids/` удалён — единственный актуальный путь находится внутри `assets/`.

## Единственный источник правды

Игра живёт только здесь: `gipromeh/Starfall`, ветка `main`. Версии в проекте Claude, в старых чатах и артефактах — архив. Текущая версия: **v78**.

## Золотое правило

**Не переписываем код. Только точечные изменения и добавления. Всё, что работает, не трогаем.** Подробности — в `STARFALL_MASTER_INSTRUCTION.yaml` (секция `golden_rule`). Файл `CLAUDE.md` в корне подтягивает это правило автоматически.

## Как работать с Claude

Начало чата:

> Подключи репозиторий gipromeh/Starfall, прочитай STARFALL_MASTER_INSTRUCTION.yaml и STARFALL_PASSPORT.md. Работай по золотому правилу: только точечные правки. Задача: ...

Конец чата:

> Обнови STARFALL_CURRENT.html, паспорт и CHANGELOG.md, закоммить (в сообщении номер версии vNN) и запушь в main.

## Правила репозитория

- Ветка `main` — рабочая версия, которая запускается без ошибок в консоли.
- Один этап из `stages` или одна версия (`vNN`) — один коммит. Сообщение коммита начинается с номера версии.
- Перед коммитом: `node --check` для основного `<script>` (команды — в паспорте, §12).
- Формат сохранений не ломать: при изменении структуры поднимать версию формата SAVE 2.0 и делать миграцию (паспорт, §14).
- Любое изменение `STARFALL_CURRENT.html` — в одном коммите с паспортом и `CHANGELOG.md`; перед коммитом `python3 tools/check_passport.py --fix` (в GitHub Actions это проверяется).

## Запуск

- Онлайн (ПК и iPhone): https://gipromeh.github.io/Starfall/ (GitHub Pages, ветка `main`, обновляется примерно за минуту после коммита).
- Локально: открыть `STARFALL_CURRENT.html` в браузере.

Нужен интернет: Three.js, tsParticles, Babylon.js и шрифты грузятся с CDN (версии закреплены, см. паспорт). `index.html` только перенаправляет на `STARFALL_CURRENT.html`.

## Управление

**ПК:** мышь — прицел, ЛКМ огонь, ПКМ/F/Пробел ракета, W/S или колесо — газ, A/D стрейф, R/C вверх/вниз, Q/Z крен, Shift форсаж, X тормоз, V разворот 180°, G боевой/горный лазер, H сопровождение, B ядерный заряд, J гиперпрыжок, Esc/P пауза, M музыка, `~`/F3 диагностика. Захвата цели нет.

**iPhone:** палец по экрану — прицел; кнопки ОГОНЬ, РАКЕТА, ФОРСАЖ, СОПР., ЛАЗЕР, ползунок газа; панель ≡ (ядерка, разворот, тормоз, горный лазер, прыжок).

## Тесты

`tests/` — сценарии Playwright (сохранения, бой, утечки, эмуляция iPhone); пути и запуск — в паспорте, §16. Реальные замеры на iPhone пока не проводились.
