# TDEF — Tower Defense 3D Scene

Изолированный проект Tower Defense внутри gipromeh/Starfall. Текущий этап — игровой прототип: базовая волна обычных врагов, строительство Gunner, автоматическая стрельба, награда за убийства, урон базе и управление симуляцией. Остальные типы врагов и башен, статусы, комбо и полная система волн ещё не реализованы.

## Запуск

Требуется Node.js 18+.

    cd TDEF
    npm install
    npm run dev

Откройте адрес, показанный Vite (по умолчанию http://localhost:5173).

Production-сборка:

    npm run build
    npm run preview

Babylon.js закреплён как npm-зависимость и включается в локальную сборку Vite. CDN для загрузки движка не используется.

## Игровой прототип 0.2

- стартовый бюджет: 100;
- Gunner: стоимость 50, урон 8, дальность 6, перезарядка 0,3 с;
- обычный враг: 40 HP, скорость 2, награда 10, урон базе 1;
- первая волна: 10 обычных врагов; количество растёт на 2 за каждую следующую волну;
- награда за завершение волны: 20 + 5 × номер волны;
- выбор площадки касанием, режим строительства, пауза и скорость ×1/×2/×3.

**Временный параметр прототипа:** здоровье базы установлено в 20 единиц только для проверки цикла поражения. Это значение не утверждено в игровом балансе и требует отдельного согласования.

## Состав сцены

- изометрическая 3D-композиция и ортографическая камера;
- замок, ворота, башни, крыши и флаги;
- извилистая дорога от входа до замка;
- восемь площадок под будущие башни;
- входная арка и красная стрелка направления;
- островной рельеф, каменная кромка, лес, кусты, вода и мост;
- направленное освещение, hemispheric fill, локальные фонари и тени;
- вращение, масштабирование и панорамирование камеры;
- горизонтальный режим как основной мобильный формат;
- HUD с ресурсами, волной, здоровьем базы и управлением Gunner.
