# TDEF — Tower Defense

Изолированный проект Tower Defense внутри gipromeh/Starfall. Игровой прототип: три типа башен, контекстное строительство, улучшение и продажа, волны обычных врагов и базовая экономика.

## Запуск

Требуется Node.js 18+.

    cd TDEF
    npm install
    npm run dev

Production-сборка:

    npm run build
    npm run preview

Babylon.js включается в локальную сборку Vite; CDN не используется.

## Игровой прототип

- стартовый бюджет: 100;
- Gunner: 50 золота, дальность 6, урон 8, перезарядка 0,3 с;
- Мортира: 100 золота, дальность 9, урон 50, радиус взрыва 2,5, перезарядка 3 с;
- Магическая башня: 90 золота, дальность 4, урон 15, цепная молния до 3 целей;
- обычный враг: 40 HP, скорость 2, награда 10, урон базе 1;
- волна: 8 + 2 × номер волны; награда за зачистку 20 + 5 × номер волны;
- улучшения до 3-го уровня, продажа за 50% вложенных средств;
- выбор площадки касанием, пауза и скорость ×1/×2/×3.

Стоимость улучшений: 40 золота для уровня 2 и 60 золота для уровня 3. Каждый уровень увеличивает урон на 50% и дальность на 10%; перезарядка сокращается на 12%.

**Временный параметр прототипа:** здоровье базы установлено в 20 единиц только для проверки цикла поражения. Это значение не утверждено в игровом балансе.

## Управление

- Нажатие на свободную площадку открывает меню выбора Gunner, мортиры или магической башни.
- Нажатие на установленную башню открывает улучшение и продажу.
- Продажа возвращает половину всех вложенных в башню средств.
- Отдельного режима строительства и действия «Стереть» нет.

## Состав сцены

Изометрическая Babylon.js-сцена с замком, дорогой, восемью площадками, островным рельефом, лесом, мостом, водой, освещением и тенями. Поддерживаются вращение, масштабирование и панорамирование камеры. Основной мобильный формат — горизонтальная ориентация.

TDEF не подключается к starfall.html и не меняет каталоги Babylon/ и Babylon New/, корневой index.html, GitHub Pages entry point или production-игру STARFALL.
