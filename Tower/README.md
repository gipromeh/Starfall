# Tower Defender — Goblin Siege

Отдельный автономный мобильный браузерный проект внутри репозитория Starfall. Игровой код хранится только в `Tower/`; существующий код Starfall не импортируется и не изменяется.

## Запуск
Откройте опубликованный адрес в Safari на iPhone: `https://gipromeh.github.io/Starfall/Tower/`.

## Управление на iPhone
- Коснуться башни в арсенале, затем свободной площадки на карте.
- Одним пальцем перетаскивать поле для вращения камеры.
- Двумя пальцами менять масштаб.
- Коснуться построенной башни, чтобы улучшить или продать её.
- Нижняя панель: запуск волны, пауза и скорость 1×/2×/3×.

Рекомендуется альбомная ориентация. Добавление на экран «Домой»: Safari → Поделиться → На экран Домой.

## Публикация
Проект публикуется как подкаталог `/Tower/` в существующем GitHub Pages сайте репозитория. Workflow собирает основной сайт Starfall как раньше и дополнительно копирует содержимое `Tower/` в `Tower/` внутри Pages artifact. Tower не участвует в сборке игрового кода Starfall.
