# Gobkit Minion Pack\n\nThe deployment workflow downloads the eight official GLB variants from the CC0 1.0 pack into this directory before publishing the Pages artifact. Files are intentionally fetched from the upstream source at build time; no placeholder `.glb` files are committed.\n\nSource and licence: https://gobkit.com/freebies and https://gobkit.com/api/free\n\nRigged characters use their embedded named animation clips and are instantiated with Three.js SkeletonUtils.clone.\n
