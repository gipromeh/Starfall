# Legacy baseline — STARFALL v85

**Источник истины:** корневой `STARFALL_CURRENT.html` на ветке `main`.  
**Зафиксировано:** 2026-10-31.  
**Версия:** v85.  
**Git commit baseline:** `05c7adb9fcfa8d29ab583c77158853902dc99838`.

## Технологическая основа исходника

- HTML5, один основной HTML-файл.
- Основной 3D-рендерер: Three.js r128.
- Babylon.js 7.0.0 уже подключён лениво для 3D-бара станции; это отдельный контекст, основной Three.js renderer на время бара приостанавливается.
- GSAP и Howler.js не подключены; анимация и звук реализованы существующими средствами.
- Платформы: desktop Chromium и iPhone Safari/PWA.
- Основные ресурсы находятся в `assets/`; пути и идентификаторы моделей являются частью контракта.

## Сохранения

- SAVE 2.0: `sf_sv2a` / `sf_sv2b`.
- Старый формат только для чтения: `sf_sv`.
- Архив при новой игре: `sf_sv_arc`.
- Дополнительные ключи: `sf_hi`, `sf_q`, `sf_as`, `sf_jk`.
- Совместимость со старым прогрессом обязательна. Существующие миграции нельзя заменять предположениями.

## Управление из корневого README

**ПК:** мышь — прицел; ЛКМ — огонь; ПКМ/F/Пробел — ракета; W/S или колесо — газ; A/D — стрейф; R/C — вверх/вниз; Q/Z — крен; Shift — форсаж; X — тормоз; V — разворот 180°; G — боевой/горный лазер; H — сопровождение; B — ядерный заряд; J — гиперпрыжок; Esc/P — пауза; M — музыка; `~`/F3 — диагностика.

**iPhone:** палец по экрану — прицел; сенсорные кнопки огня, ракеты, форсажа, сопровождения и лазера; ползунок газа; дополнительная панель для ядерного заряда, разворота, тормоза, горного лазера и прыжка.

## Существующие игровые подсистемы

- Пять звёздных систем, планеты, орбиты, спутники и кольца.
- Станции, сервисы, 3D-холл/бар и четыре персонажа экипажа: Зорг, Векса, Шшиила, Брук.
- Торговля, экономика систем, репутация, рыночные события, груз и средняя закупочная стоимость.
- Корабли игрока, верфь, оборудование, оружейные слоты, ракеты и тюнинг.
- Астероидная добыча, руда, грузовой трюм.
- Нейтральные транспорты, три типа туристических кораблей, патрули и пиратские группы.
- Контракты, диалоги, сюжетные и системные события.
- Бой, четыре типа пиратов, боссы, снаряды, ракеты, ядерный заряд, столкновения, разрушения, дроп и награды.
- Карта, навигация, гиперпрыжки, орбитальные и станционные взаимодействия.
- Мобильный HUD, сенсорное управление, профили качества и жизненный цикл страницы.

## Существующие тесты

Каталог `tests/` содержит регрессии сохранений, полёта, утечек, диагностики, iPhone-эмуляции, ядерного удара и пиратской эскадрильи. CI запускает Playwright/Chromium, включая `t8_nuke.js`, `t6_probe.js`, `t11_pirate_fleet.js`. Использовать их как baseline, не переносить и не переписывать под Babylon без сохранения исходных тестов.

## Правило сравнения

Для каждого элемента исходника фиксировать:
1. исходные функции, данные, состояния и DOM/UI точки;
2. наблюдаемое поведение и входные условия;
3. Babylon-эквивалент;
4. тест на совпадение поведения;
5. статус: not started / in progress / parity / regression / approved deviation.

Этот документ не заменяет корневой паспорт: перед переносом конкретной механики открыть соответствующий раздел `../STARFALL_PASSPORT.md` и тесты.
