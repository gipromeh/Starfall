# STARFALL — Galaxy Map integration

## Реализация
- ED3D интегрирован не как отдельный legacy-бандл, а как адаптация его 3D-карты, поиска, фильтрации, выбора систем и маршрутов к Three.js r128 проекта.
- Используется существующий `THREE.WebGLRenderer`; второй WebGL-контекст не создаётся. DOM-слой карты прозрачен, поэтому 3D-сцена видна под интерфейсом.
- При открытии карты игровой режим переключается в состояние `galaxy`, игровой рендер заменяется рендером карты.
- Пять локальных систем STARFALL отображаются отдельным кластером с условными координатами. Выбранная локальная система может запускать существующий гиперпрыжок из игрового полёта.
- Внешние записи Spansh доступны для просмотра, поиска и справочного планирования. Фильтр обитаемых систем отключается, если источник не содержит population-поля; текущий manifest подтверждает `population_field_records: 0`.
- Маршруты между STARFALL и Spansh блокируются: локальные игровые координаты условные, а внешние координаты указаны в ly.

## Источник данных
Карта загружает `data/elite-dangerous-lite/systems.jsonl.gz` относительно URL игры. До распаковки проверяются формат manifest, размер сжатого файла и SHA-256 через Web Crypto. Затем данные распаковываются потоково через `DecompressionStream('gzip')`; количество строк сверяется с `manifest.records`. Если файл отсутствует или API распаковки недоступен, карта остаётся доступной с пятью локальными системами STARFALL.

## Производительность
- Один общий WebGL-контекст.
- Каталог визуализируется одним `THREE.Points`, а не десятками тысяч Mesh.
- Фоновые звёзды ограничены 900 на coarse pointer и 1800 на desktop.
- Вращение поддерживает pointer drag; на время карты `touch-action: none` включается только на canvas, а при закрытии восстанавливается исходное значение. Масштабирование доступно колесом мыши и экранными кнопками `+`/`−`.
- URL архива содержит SHA-256 из manifest для инвалидации старого cache; manifest проверяется до чтения gzip.
- Проверка ближайшей точки выполняется только по нажатию; список поиска ограничен 14 результатами.

## Текущий каталог
В репозитории опубликован `data/elite-dangerous-lite/systems.jsonl.gz`: 50 000 записей, около 1.4 MB сжатых данных. Точные метаданные выборки и SHA-256 находятся рядом в manifest. Наличие файла подтверждено в `main`; полный дамп галактики не публикуется.

## Ограничения
- Lite — выборка из месячного Spansh systems dump, а не полная галактика.
- Внешние системы пока не являются игровыми секторами: у них нет симуляции STARFALL, экономики, миссий и перехода гиперпрыжком.
- Координаты пяти локальных систем условные и не являются координатами Elite Dangerous.
- Физический тест на iPhone Safari ещё требуется; потоковая распаковка требует поддержки `DecompressionStream`.

## Проверка источника и фильтр населения

Перед загрузкой карты проверяются формат manifest, размер сжатого файла и SHA-256. После потоковой распаковки число JSONL-записей должно совпасть с `manifest.records`; иначе каталог отклоняется и остаётся доступен локальный кластер STARFALL.

Текущий месячный snapshot Spansh имеет `population_field_records: 0`. Поэтому фильтр «ОБЖИТЫЕ» отключён с подписью «НЕТ ДАННЫХ». Он включается только при наличии population-поля в источнике и хотя бы одной системы с населением в выборке. Значения населения не синтезируются.


## Процедурные внешние системы
- Внешняя система генерируется детерминированно по ID записи Spansh. Повторное посещение сохраняет тот же тип звезды, состав и порядок орбит планет, вероятность пояса астероидов и орбитальной станции.
- В Galaxy Map доступен отдельный режим орбитального исследования: звезда, планеты и спутники, орбитальные дорожки, газовые кольца, InstancedMesh-пояс астероидов и орбитальная станция. Список объектов позволяет фокусировать камеру на выбранном теле.
- Исследовательская сцена использует общий Three.js renderer карты. Временная сцена удаляется при возврате; геометрии и материалы освобождаются.
- Внешние станции являются визуальными объектами исследования. Они не подключены к торговле, ценам, грузу, кредитам, миссиям или сохранениям STARFALL. Экономика пяти основных систем не меняется.
- Поля спектрального класса и состав планет синтезируются генератором: текущая lite-выборка Spansh не предоставляет надёжной физической модели планет и классов звёзд.
- Это орбитальный режим исследования внутри Galaxy Map, не полноценный полётный сектор с посадкой и экономикой.
