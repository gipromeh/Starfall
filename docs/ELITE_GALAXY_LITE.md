# STARFALL — Elite Dangerous Lite dataset

## Что это

Компактный каталог звёздных систем для карты и навигации: ID, имя, координаты, население, принадлежность, тип правительства, безопасность и экономика (если поле присутствует в источнике).

Это **не полная галактика** и не замена full Spansh dump:
- тела, планеты, звёзды и станции не включаются как отдельные записи;
- workflow использует `systems_1month.json.gz` — источник систем, обновлённых/представленных в месячном срезе;
- по умолчанию выбираются до 50 000 систем детерминированной reservoir-выборкой с фиксированным seed; выборка воспроизводима и не смещена к началу файла, но не гарантирует равномерное покрытие каждого сектора;
- итоговый gzip ограничен 35 MiB, чтобы отдельный файл был ниже лимита GitHub в 100 MB.

Источник: https://downloads.spansh.co.uk/systems_1month.json.gz  
Каталог дампов: https://www.spansh.co.uk/dumps

## Формат

`data/elite-dangerous-lite/systems.jsonl.gz` — gzip-сжатый JSON Lines. Одна система на строку. Ключи сокращены для уменьшения размера:

| Поле | Значение |
|---|---|
| id | Spansh id64, строка |
| n | имя системы |
| x, y, z | координаты, округление до 0.01 ly |
| p | население |
| a, g, s | allegiance, government, security |
| e, e2 | primary/secondary economy |
| f | controlling faction |
| bc | body count |

Рядом находится manifest с числом записей, источником, размером и SHA-256.

## Публикация в GitHub

1. Откройте репозиторий STARFALL → Actions → **Update Elite Dangerous lite dataset**.
2. Нажмите Run workflow.
3. Выберите лимит записей (по умолчанию 50 000) и при необходимости inhabited-only.
4. Workflow скачает месячный Spansh systems dump, потоково сформирует компактный каталог, проверит лимит 35 MiB и закоммитит результат в `main`.

Для локальной сборки:

```bash
python -m pip install -r requirements-data.txt
python tools/export_elite_lite.py --source systems_1month.json.gz \
  --output data/elite-dangerous-lite/systems.jsonl.gz --max-systems 50000 --max-mb 35
```

Не помещайте исходный архив в репозиторий. Он используется только во время генерации.

## Обновление и ограничения

Месячный срез меняется со временем. Повторный запуск workflow заменяет версионированный dataset в репозитории новым коммитом. Сохраняйте manifest вместе с данными.

GitHub Pages может раздавать этот файл как статический asset после включения Pages для ветки/папки, но приложение пока не подключено к нему. Для браузера gzip должен отдаваться сервером с корректным `Content-Encoding: gzip`; иначе загружать файл через `DecompressionStream('gzip')` и читать JSONL построчно в Worker. Не декодировать весь файл в один большой JSON-массив.

Лицензия/условия повторного распространения Spansh-данных и требуемая атрибуция должны быть проверены по текущим условиям источника перед публичным распространением.
