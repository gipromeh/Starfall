# STARFALL v86 — интеграция решений в базу v85

## База
Корневой `STARFALL_CURRENT.html` из `gipromeh/Starfall`, meta version `v85`, Three.js r128. Имя основного файла сохранено.

## Изменения
- Баланс «Головореза» type 0: speed multiplier 1.12, turn coefficient 1.00, steering acceleration 48, initial speed 20.
- Уменьшена геометрия ближнего LOOP-манёвра type 0; остальные классы не затронуты.
- Добавлены три процедурные неоновые надписи и светящиеся полосы только на модели type 0.
- Радар: независимый сбор контактов, 500 м / 1 км / 2 км, подписи колец, символы классов, векторы движения, вертикальная индикация, выделение цели и стрелки вражеских контактов вне диапазона.
- Meta version обновлён до v86; основной HTML-файл остался `STARFALL_CURRENT.html`.

## Проверки
- Все встроенные inline JavaScript-блоки прошли синтаксический разбор в V8.
- Проверены три диапазона радара, наличие трёх надписей и коэффициентов type 0, отсутствие дублирования radar().
- Реальный запуск Chromium/PC и Safari/iPhone не выполнен. Нужна визуальная проверка положения накладок на GLB и поведения радара в бою.
